# Conway's Game of Life
### A responsive implementation of the classic Conway's Game of Life, in the terminal!
![screenshot](image.png)

## How to use
- Type ```python conway.py``` to view a summary   
```
---------------------
Conway's Game of Life
[usage] python conway.py <pattern> <theme>(optional) -d/--debug (debug, optional)

patterns:
0 - checkerboard
1 - diagonals
2 - random

theme:
0 - black and white
1 - blue and yellow
2 - black and cyan
3 - white and green

debug: displays neighbor counts
```

- Change the terminal resolution using ```ctrl + scroll up/down```   
- There's also a ```FRAMERATE``` setting hidden inside of conway.py
